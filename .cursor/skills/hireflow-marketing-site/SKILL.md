# HireFlow Marketing Website

- Explain the user problem and HireFlow's concrete value in plain language.
- Keep marketing pages separate from authenticated product routes while maintaining shared brand/design tokens.
- Provide functional Start Free, Sign In, Explore Product and feature CTAs.
- Use truthful current screenshots and product capabilities; label roadmap features as upcoming.
- Build clear feature pages, audience pages where genuinely distinct, pricing, resources, trust/security and help pages.
- Use original helpful content; avoid thin, duplicated, fabricated or keyword-stuffed pages.
- Implement technical SEO and structured data only according to current official guidelines.
- JobPosting structured data is for eligible individual job detail pages only and only with accurate, current data and permitted publication; never on listing/search pages.
- Measure conversion with privacy-respecting analytics and appropriate consent.
- Verify mobile usability, accessibility, performance and route behavior.
