# Customer journey

**Date:** 2026-11-21

```
Visitor (marketing, no login wall)
  → Start Free or Explore Product
  → Sign up (email/password; Google optional when configured)
  → Onboarding (skip allowed)
  → Empty Overview (completeness, Free plan, inbox 0)
  → Empty Jobs / Resume Studio / Applications / Prepare / Insights
  → Settings: usage, export, delete
  → later Phase 2 Discover
  → later Phase 3 resume + explained match
  → later Phase 4 Applied
  → later Phase 5 vault + pack
```

Failure states stay honest: unauthenticated URLs go to sign-in; empty modules explain the phase; Pro CTAs say not live; research features never appear as upgrade buttons.
